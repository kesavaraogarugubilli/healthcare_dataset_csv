# 🏥 Healthcare Data Analysis (EDA) Project

## 📌 Project Overview
This project focuses on performing **Exploratory Data Analysis (EDA)** on a healthcare dataset using Python. The main objective is to clean, analyze, and visualize healthcare data to uncover meaningful insights that can support data-driven healthcare decisions.

The project demonstrates data preprocessing, statistical analysis, and visualization techniques commonly used by Data Analysts.

---

## 🎯 Objectives

- Clean and preprocess healthcare data
- Handle missing values and duplicate records
- Perform exploratory data analysis (EDA)
- Identify trends and patterns in patient information
- Visualize important healthcare metrics
- Generate insights for better decision-making

---

## 📊 Dataset Features

The dataset contains healthcare-related information such as:

- Patient ID

- Gender
- Blood Group
- Medical Condition
- Admission Type
- Hospital
- Doctor
- Billing Amount
- Insurance Provider
- Medication
- Test Results

- Discharge Status
